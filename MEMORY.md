## What this app is
A Windows desktop utility (`agent_scaffolder.py`, single-file CustomTkinter app) that
packages a selected project with Repomix and sends it to the Anthropic API three times
to generate three Markdown *instruction* documents for an AI coding assistant:
`agents.md`, `bug_hunter.md`, `enhancement_agent.md`. It does not run or execute an
autonomous agent — it only writes configuration/instruction text, saved to
`%USERPROFILE%\Desktop\Agent Outputs\<project>`.

Notably self-hosting: this repo's own `agents/*.md` files were generated by this tool
and are now the dev-instructions the maintainer follows when working on the tool
itself (see `CONTRIBUTING.md`).

## Architecture invariants — do not break these without an explicit request
- Single-file app (`agent_scaffolder.py`). No module split.
- CustomTkinter only; `pack()` layout only (no grid/place, no ttk, no Tk StringVar/BooleanVar).
- Segoe UI font; grey secondary text/buttons vs accent primary action.
- API key lives in Windows Credential Manager via `keyring` (service `AgentScaffolderApp`,
  account `AnthropicAPIKey`) — never JSON, never plaintext.
- Long-running work (Repomix subprocess, Anthropic calls) runs on a daemon
  `threading.Thread`, never the Tk main loop; widget updates from that thread must go
  through `self.after(0, ...)`.
- `refresh_ui_state()` is the single source of truth for button/status enablement — any
  new control should extend it rather than adding one-off enable checks.
- `_suppress_project_event` must guard every programmatic `project_menu.set(...)`.
- Output contract: `Desktop/Agent Outputs/<project>` — do not relocate without being asked.
- `projects.json` / `last_project.json` are local, gitignored, user-editable while the
  app is closed.

## Model selection (added 2026-09-10, explicit user request)
Settings has a "Generation model:" picker (Haiku 4.5 / Sonnet 5 / Opus 5, live pricing
in the labels) — see `resolve_model()`, `MODEL_CHOICES`, `load_model_choice()` /
`save_model_choice()` in `agent_scaffolder.py`. Resolution order: `AGENT_SCAFFOLDER_MODEL`
env var > `model_choice.json` (local, gitignored) > `DEFAULT_MODEL` (`claude-sonnet-5`).
Currently seeded to `claude-haiku-4-5` on this machine per the user's cost-conscious
development request — change any time via Settings. Full detail: ROADMAP.md "Since 1.1".
**Note for future sessions:** "model/prompt picker UI" is no longer in the rejected
list below — it shipped. Don't re-reject it if asked to extend it further.

## Explicitly rejected (per notes_002.txt) unless the user asks again
Progress bar/spinner, grid()/place()/ttk/Qt/web UI, Tk variable bindings, a second
credential store, writing generated files into the target repo, changing the Desktop
output root, dark-mode toggle — these were deliberately scoped out of the compact-utility
design. Don't reintroduce them under a "polish" pass without confirming it's wanted.
(A model picker was on this list originally; it's now implemented — see above.)
